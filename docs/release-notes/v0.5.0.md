# co-op V0.5.0 and earlier

Released 2026-10-29.

The first versions, from the start of the project.

## Librarian

- **Library:** browse the OP-1 drive, preview patches, and rename, move, copy and delete them.
- **Backup and restore:** download the patch tree as a zip, and restore from one after comparing it
  with the drive.
- **Read-only sources:** browsers that cannot write to a folder collect changes in a zip to copy over.
- **Inspector:** drop a single patch to see how co-op reads it.

## Firmware

- **Profiles:** stock OP-1, hundekraft and opus, detected from the drive, with a warning for patches
  a firmware cannot play.

## OP-1 over USB

- **Remembered firmware:** your firmware choice is reused the next time you connect.
- **Check over USB:** confirms hundekraft 3.x and lists your plugins, without disk mode.

## Plugin library

- **Plugins tab:** community plugins with screenshots, manuals, credits and source links.
- **Install:** hundekraft plugins install over USB, and opus plugins copy to `mods/`.
- **Plugin prompts:** installing a patch that needs a plugin offers to install it too.

## Community

- **Packs:** a catalogue of community patch packs to preview and install.
- **op1.fun:** browse, install and upload patches.
- **Feedback:** send a bug report or idea from the site.
