# co-op V0.10.0

Released 2026-11-14.

## coop firmware

co-op now has its own OP-1 firmware, coop, with a stereo signal path, a second effect slot and a
second LFO, a settings menu, and synth and effect plugins of its own.

- **Build firmware tab:** give it your own stock `op1_246.op1` and it builds coop in the browser.
  co-op only holds coop's own changes, never TE's firmware, and checks the result byte for byte
  before you can save it. The tab replaces the Inspector and has the coop manual on it.
- **Settings tab:** choose your OP-1's firmware (stock, hundekraft, opus or coop). The Library's
  firmware menu and the Plugins tab follow it from the first page load.
- **coop plugins over USB:** the Plugins tab's **On your OP-1** panel lists the coop plugins on
  the device, switches them on and off, removes them and installs new ones. Every change asks for
  a power cycle.
- **First coop plugins:** the saw and rings synth engines, the nine effects (bitcrusher, drive,
  ensemble, freq shift, tape drive, tape echo, wavefolder, and the new cs hall and cs plate),
  each with its own screen. The effects need coop e10, the build the Build firmware tab makes.

## Plugins

- **Many more plugins:** hundekraft's workshop plugins, Opus's plugins and community plugins such
  as erdtree, Castle and Bloodmoon are now listed under their real authors. co-op links to the
  author's page and hosts no copy.
- **Install over USB from the author:** a listed hundekraft plugin whose repo has the built `.knl`
  gets **Install over USB**. co-op fetches it from the author, checks it against the index and
  installs it like a hosted one.
- **One plugin, a build per firmware:** a plugin shows once, with the file, version and
  requirements for the firmware you've picked. coldsoldr's effects, saw and rings now have
  hundekraft, opus and coop builds.
- **Update checks:** plugin listings are checked daily against their authors' repos and releases.
- **Submit a plugin:** a tab per firmware explains what each kind of plugin needs, and a new
  release guide for plugin authors is at `#release-guide`.
- **Author groups** start closed. A search or filter opens the groups it finds.

## Patches and Library

- **Copy community patches** to My folder or download them as a zip, from the Patches tab or a
  whole pack at once. co-op asks for write access to your folder when it needs it.
- **Audition pack patches** on the OP-1, like your own.
- **Manage files** on the Library and My folder pages: bulk tools, per-row actions, folder trees,
  and copies from the OP-1 to your computer.
- **Rename** changes the patch's name and its file name in one go.
- **New packs:** gl1tch (drums) and melod1c (synths).

## Known limitations

- coop is new. Back up your OP-1 before you flash it.
- coop plugins only run on coop, and hundekraft and opus plugins don't run on coop.
