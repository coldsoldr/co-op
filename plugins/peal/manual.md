# Peal

Peal plays English change ringing. Pick PEAL with Shift + seq, then hold 3 to 8 keys: each is a bell, and the method changes their order on each row. One or two keys are silent. When you release the last key, the current row finishes and stops. Hold Shift while releasing it to keep ringing. Hold Shift and turn orange left to stop.

## Who made it

From op1r, ported to kennel by Hundekraft.

## Get it

Peal is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
