# Tape undo / redo

Every recording can be undone, up to seven steps back: takes, punch-ins, overdubs, loop takes, lift, drop, slide (Shift + blue), split, join and the tape edits below. It works with the tape stopped or playing. Sliding a clip takes two undo steps: the first undoes the drop, the second restores the lift.

## Who made it

Rebuilt by hundekraft from how Maiko Pruett's #249 and #250 work; none of Maiko's code is used.

## Get it

Tape undo / redo is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
