# Oracle

Oracle and Peal are sequencers from Musica Obscura. Pick either with Shift + seq.

## Who made it

From op1r, ported to kennel by Hundekraft.

## Get it

Oracle is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
