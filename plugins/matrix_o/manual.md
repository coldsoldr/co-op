# matrix

matrix is an LFO type with up to eight rows. Each row is an LFO or an envelope with an amount and a target. Pick it on the LFO page with Shift + T4. It's LizardMan's, and ticked from the start. A sound saved with the earlier MATRIX opens in this one, but its rows may sound different.

## Get it

matrix is part of hundekraft 3.3.1, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
