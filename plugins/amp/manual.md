# Amp

*Your input is the instrument.*

Amp turns the OP-1's live input into the instrument. The mic, line, radio or USB signal runs through a compressor, a tone control and an amp with a speaker cabinet. No key needs to be held. It is inspired by the OP-1 Field's live-input instrument.

## Get it

Amp is part of hundekraft 3.3.1, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.

On op1r 73 it is the plugin file `amp.op1p`: tick it in [op1r's web patcher](https://pcppcp.github.io/op1r/web/) (Connect OP-1 installs it over USB), or download it here with op1r chosen in Settings.
