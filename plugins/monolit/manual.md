# MONOLIT

*Three oscillators into a ladder filter, for bass and leads.*

Every note plays three oscillators through a four-pole ladder filter. Each knob moves several settings at once, so every position gives you something usable. The amp envelope on T2, glide and the play modes work as on the other synths. Push blue, green or white for page 2.

## Get it

MONOLIT is part of hundekraft 3.3.2, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.

On op1r 77 it is the plugin file `monolit.op1p`: tick it in [op1r's web patcher](https://pcppcp.github.io/op1r/web/) (Connect OP-1 installs it over USB), or download it here with op1r chosen in Settings.
