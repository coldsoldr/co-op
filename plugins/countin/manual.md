# Count-in

With the tape stopped, hold REC and press metronome. You get 4, 8 or 16 clicks, then the tape starts recording on the next beat. You can let go of REC. STOP cancels. Set the length on the settings page.

## Who made it

From op1r, ported to kennel by Hundekraft.

## Get it

Count-in is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
