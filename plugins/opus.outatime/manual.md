# outatime

A time-travel synth engine. Each voice is three oscillators that morph from 1955 (warm) through 1985 (saws) to 2015 (glassy); speed sends them drifting through time, power is a strong overdrive in four types (warm, hard, tube, fold: on shift + orange, kept with each sound) that stays as loud at any amount, and trail ignites each note and burns it down. Its page is a time machine on the road: it drives while you play and lights a fire trail at the set speed. An LFO such as the matrix can move its shift layer.

## Get it

outatime 1.4.3 is a plugin for Opus 2.0 beta 4.1, LizardMan's mod for the original OP-1 (firmware 246): one file in the starter pack, or on its own, in [Opus's releases](https://github.com/LizardMan245/opus/releases). Copy the `.opmod` into the mods folder on the OP-1's disk. co-op lists it for reference and hosts no copy. Opus's plugins are © LizardMan, free to use and share.
