# Steve

*Steve Reich's phasing as an effect.*

Steve by pcppcp records a short loop and plays it back as two to four copies. In drift mode the copies run at slightly different speeds, so they slide apart and back together, like Reich's *It's Gonna Rain*. In steps mode the copies jump ahead one unit at a time and lock there, like *Piano Phase*.

## Who made it

From op1r, ported to kennel by Hundekraft.

## Get it

Steve is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
