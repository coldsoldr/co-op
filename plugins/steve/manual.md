# Steve

*Steve Reich's phasing as an effect.*

Steve by pcppcp records a short loop and plays it back as two to four copies. In drift mode the copies run at slightly different speeds, so they slide apart and back together, like Reich's *It's Gonna Rain*. In steps mode the copies jump ahead one unit at a time and lock there, like *Piano Phase*.

## Who made it

From op1r, ported to kennel by Hundekraft.

## Get it

Steve is part of hundekraft 3.3.1, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.

On op1r 73 it is the plugin file `steve.op1p`: tick it in [op1r's web patcher](https://pcppcp.github.io/op1r/web/) (Connect OP-1 installs it over USB), or download it here with op1r chosen in Settings.
