# trigger guard

A worn key that fires twice plays once: on the keyboard's note keys, a second press inside the window (50 ms to start, 10 to 300) is dropped. One window per note or one for all keys, and "false releases held" keeps a note sounding through a bounce. The synth, the drums, the sequencers and USB MIDI out all get the cleaned keys. The idea is u/Andromax_sussybaka's.

## Get it

trigger guard 1.1.0 is a plugin for Opus 2.0 beta 4.1, LizardMan's mod for the original OP-1 (firmware 246): one file in the starter pack, or on its own, in [Opus's releases](https://github.com/LizardMan245/opus/releases). Copy the `.opmod` into the mods folder on the OP-1's disk. co-op lists it for reference and hosts no copy. Opus's plugins are © LizardMan, free to use and share.
