# Granular

*Plays the slot's sample as grains.*

A granular engine that plays a sampler recording as clouds of grains. C4 plays the recording at its original speed. Each grain is centred on the position and stays inside the recording.

## Who made it

From op1r, ported to kennel by Hundekraft.

## Get it

Granular is part of hundekraft 3.3.2, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.

On op1r 77 it is the plugin file `granular.op1p`: tick it in [op1r's web patcher](https://pcppcp.github.io/op1r/web/) (Connect OP-1 installs it over USB), or download it here with op1r chosen in Settings.
