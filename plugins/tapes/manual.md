# Four tapes

The OP-1 has four tapes. Each has its own four tracks, clips, loop, position, tempo, album and undo history.

## Who made it

Rebuilt by hundekraft from how Maiko Pruett's #249 and #250 work; none of Maiko's code is used.

## Get it

Four tapes is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
