# Hollow Saint

*A haunted hurdy-gurdy.*

Hollow Saint by SammiBabe666 is a hurdy-gurdy in a cathedral. Each note is a bowed melody string. Under it run two drone strings, root and fifth, and the trompette, a string whose buzzing bridge slaps on the strokes of the wheel. The wheel turns in time with the OP-1's tempo. Then the sound goes into a stone room that darkens and rings, and turned up high it strikes a distant bell on each note. It's all synthesis, no samples.

## Who made it

In the synth list it's called hollowsaint. It's from Cathedral of the Hollow Saint by SammiBabe666. Hundekraft brought it to the OP-1.

## Get it

Hollow Saint is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
