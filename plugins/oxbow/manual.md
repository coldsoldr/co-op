# Oxbow

*An OB-style polysynth, after zvenson's OberVave.*

Two oscillators with sync and cross-modulation into a state-variable filter, an internal filter envelope and a little vintage drift per voice. It comes from OberVave, zvenson's polysynth for the M-VAVE FM-1. Each encoder is a macro that moves several of these at once, so every position is a usable sound. Save and recall sounds with the normal OP-1 presets.

## Who made it

Port of OberVave by zvenson (GPL-3.0).

## Get it

Oxbow is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
