# MBIRA

*A thumb piano with bottle caps.*

A kalimba: every note plucks a steel tine, rings in a wooden box and fades by itself. Holding the key doesn't stretch the ring, but letting go starts the release on T2, so a short release cuts it. Turn up the buzz and bottle caps rattle while the tine swings.

## Get it

MBIRA is part of hundekraft 3.3.2, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.

On op1r 77 it is the plugin file `mbira.op1p`: tick it in [op1r's web patcher](https://pcppcp.github.io/op1r/web/) (Connect OP-1 installs it over USB), or download it here with op1r chosen in Settings.
