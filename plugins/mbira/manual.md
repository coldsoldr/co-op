# MBIRA

*A thumb piano with bottle caps.*

A kalimba: every note plucks a steel tine, rings in a wooden box and fades by itself. Holding the key doesn't stretch the ring, but letting go starts the release on T2, so a short release cuts it. Turn up the buzz and bottle caps rattle while the tine swings.

## Get it

MBIRA is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
