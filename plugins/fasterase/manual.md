# Fast tape erase

The stock erase gesture (Shift + tape, then press T1 to T4 together) now only clears the parts of the tape that have audio, so it takes seconds instead of minutes. It can't be undone, and it clears the undo history.

## Get it

Fast tape erase is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
