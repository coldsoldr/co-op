# dimension

dimension is a six-voice synth by LizardMan. One oscillator morphs from noise through pulse, square and saw to saw with a sub. It runs into a four-pole low-pass filter and a slow ensemble that thickens the sound.

## Get it

dimension is part of hundekraft 3.3.1, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
