# Drum+

drum+ is a second drum instrument on top of a sampled drum kit. It adds per-pad sound design: pitch envelope, retrigger, drive, choke groups, an envelope and a filter for every pad. Pads you haven't touched sound like stock.

## Who made it

From op1r, ported to kennel by Hundekraft.

## Get it

Drum+ is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
