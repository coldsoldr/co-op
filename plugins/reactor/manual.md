# REACTOR

*A power plant you play like a synth.*

Four sine waves sit in a loop and modulate each other, like fuel rods in a core. Heat pushes the loop and cooling holds it back. While cooling keeps up you get clean FM; turn up the heat and the tone grows, bends and starts to howl. The fun is finding how close to the edge you can play.

## Get it

REACTOR is part of hundekraft 3.3.1, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.

On op1r 72 it is the plugin file `reactor.op1p`: tick it in [op1r's web patcher](https://pcppcp.github.io/op1r/web/) (Connect OP-1 installs it over USB), or download it here with op1r chosen in Settings.
