# blot

*A TB-303 style bass synth.*

blot (from op1r) is an acid bass line synth. A saw-to-square oscillator goes into a model of the TB-303's own filter (after Open303), with its own decaying filter envelope, so the bass holds steady under heavy resonance. Notes played hard (velocity 100 or more) are accented: the filter sweeps further and the note plays louder, and the accent fades with the Decay knob. For slides, set the play mode to mono or legato and use the OP-1's portamento. The screen is an acid house smiley: the eyes follow the cutoff, the smile the resonance, the mouth the envelope, and it drips with the decay.

## Who made it

Filter after Open303's TB-303 filter by Robin Schmidt (MIT); from op1r, ported to kennel by Hundekraft.

## Get it

blot is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
