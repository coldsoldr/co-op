# chorus

Rate, depth, delay (short like a flanger, long like a doubled part) and mix; voices and feedback under shift. Its page draws each voice as a stack of moving waves in its encoder's colour and shows the four values at the top right. It draws with orbit3d, so keep that in mods beside it.

## Get it

chorus 2.3.0 is a plugin for Opus 2.0 beta 4.1, LizardMan's mod for the original OP-1 (firmware 246): one file in the starter pack, or on its own, in [Opus's releases](https://github.com/LizardMan245/opus/releases). Copy the `.opmod` into the mods folder on the OP-1's disk. co-op lists it for reference and hosts no copy. Opus's plugins are © LizardMan, free to use and share.
