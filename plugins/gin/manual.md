# Gin

Gin is a drum synthesiser by SquareWave Studio, based on Eric Lewis's libpo32. Open the drum engine browser with Shift + T1 and select GIN. DBOX and DRUM+ remain available.

## Who made it

Based on libpo32 by Eric Lewis; factory sounds adapt CNTR RNDM's kits. Ported to kennel by Hundekraft.

## Get it

Gin is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
