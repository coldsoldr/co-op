# DIMENSION

*Six voices and a thick ensemble.*

DIMENSION is a six-voice synth by LizardMan. One oscillator morphs from noise through pulse, square and saw to saw with a sub, into a four-pole resonant low-pass filter and a slow ensemble that thickens the sound. Hold Shift for a filter envelope with accent and slide, for 303-style lines.

## Get it

DIMENSION is part of hundekraft 3.3, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
