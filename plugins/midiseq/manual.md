# MIDI sequencer

A sequencer for notes and MIDI CCs on four tracks that play along with the tape. Start recording with the first note or a count-in, then quantize the timing if needed. Each track takes notes from the keyboard, from the OP-1's sequencers or from a USB MIDI channel, and plays them to the synth, into a sequencer or out over USB MIDI.

## Who made it

From op1r, ported to kennel by Hundekraft.

## Get it

MIDI sequencer is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
