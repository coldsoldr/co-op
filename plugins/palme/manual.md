# Palme

*Twelve sympathetic strings and a gong.*

The palm-shaped string loudspeaker of the Ondes Martenot. Twelve strings, tuned chromatically from a root, ring in sympathy with what you play. Page 2 morphs the soundboard into a gong.

## Who made it

Musica Obscura by ultralazr, from op1r, ported to kennel by Hundekraft.

## Get it

Palme is part of hundekraft 3.3.1, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.

On op1r 73 it is the plugin file `palme.op1p`: tick it in [op1r's web patcher](https://pcppcp.github.io/op1r/web/) (Connect OP-1 installs it over USB), or download it here with op1r chosen in Settings.
