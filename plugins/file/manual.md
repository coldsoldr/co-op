# File / storage

- Hold Shift and press COM. The COM screen opens.
- On the OP-1 tab (T1), hold Shift and press COM again. FILE opens. The same keys switch back. In CTRL, DISK or OPT, Shift + COM does what it always did; press T1 first to reach FILE.

## Who made it

Rebuilt by hundekraft from how Maiko Pruett's #249 and #250 work; none of Maiko's code is used.

## Get it

File / storage is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
