# plate

A plate reverb in the effect list, with its own page and a shift layer. It rests once its tail is over, so a plate on silence costs next to nothing, and a size or pre-delay moved by an LFO glides instead of clicking.

## Get it

plate 2.0.10 is a plugin for Opus 2.0 beta 4.1, LizardMan's mod for the original OP-1 (firmware 246): one file in the starter pack, or on its own, in [Opus's releases](https://github.com/LizardMan245/opus/releases). Copy the `.opmod` into the mods folder on the OP-1's disk. co-op lists it for reference and hosts no copy. Opus's plugins are © LizardMan, free to use and share.
