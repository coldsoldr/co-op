# scales and chords

Play in a scale and in chords, set from quick pages on the synth's T1. The chord's name shows at the top left, in a box as wide as the name (the setting "chord popup" hides it).

## Credits

The idea comes from stfj's note-quantization patch for 246; written from the ground up.

## Get it

scales and chords 1.2.0 is a plugin for Opus 2.0 beta 4.1, LizardMan's mod for the original OP-1 (firmware 246): one file in the starter pack, or on its own, in [Opus's releases](https://github.com/LizardMan245/opus/releases). Copy the `.opmod` into the mods folder on the OP-1's disk. co-op lists it for reference and hosts no copy. Opus's plugins are © LizardMan, free to use and share.
