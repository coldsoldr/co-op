# stock help

The OP-1's own help screen is back, on FN held alone (300 ms to start, a setting). Any other key or a turn hides it first, so FN's combinations never show it, and shift + FN opens the date and time. Without this plugin the help costs no memory. It shares FN held with the monitor: keep one of the two switched on.

## Get it

stock help 1.0.2 is a plugin for Opus 2.0 beta 4.1, LizardMan's mod for the original OP-1 (firmware 246): one file in the starter pack, or on its own, in [Opus's releases](https://github.com/LizardMan245/opus/releases). Copy the `.opmod` into the mods folder on the OP-1's disk. co-op lists it for reference and hosts no copy. Opus's plugins are © LizardMan, free to use and share.
