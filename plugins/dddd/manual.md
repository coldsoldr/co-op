# dddd

*A wall of harsh noise.*

dddd by pcppcp is a noise instrument. All the keys you hold play one shared sound. The lowest key you hold drives it. Each held key also adds a tap to the feedback loop (the four newest count), so a chord changes the texture more than the harmony. Random "hands" keep moving the sound on their own.

## Who made it

From op1r, ported to kennel by Hundekraft.

## Get it

dddd is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
