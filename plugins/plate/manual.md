# Plate

*A plate reverb, after Maiko.*

Plate diffuses the input into a reverb tail. Decay sets how long it rings; tone sets how bright it stays. The artwork is Maiko's, used with permission. Synth, drum and master each have their own reverb. On a synth or the drums it is mono; the master is stereo.

## Who made it

Reconstructs Maiko Pruett's #250 algorithm and artwork, used with permission.

## Get it

Plate is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
