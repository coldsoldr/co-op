# Matrix LFO

*Eight modulators in one LFO slot.*

MATRIX is an LFO type by LizardMan. It has up to eight rows, and each row is an LFO or an envelope with an amount and a target. Pick it on the LFO page with Shift + T4.

## Get it

Matrix LFO is part of hundekraft 3.3, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
