# halloween

A Halloween colour theme for the whole OP-1 (above, on outatime's page), and the first plugin with no code at all: a theme is a plugin too.

## Get it

halloween 1.0.0 is a plugin for Opus 2.0 beta 4.1, LizardMan's mod for the original OP-1 (firmware 246): one file in the starter pack, or on its own, in [Opus's releases](https://github.com/LizardMan245/opus/releases). Copy the `.opmod` into the mods folder on the OP-1's disk. co-op lists it for reference and hosts no copy. Opus's plugins are © LizardMan, free to use and share.
