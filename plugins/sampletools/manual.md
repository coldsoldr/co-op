# Sampler tools

Three tools on the stock sampler screens, for a synth sampler sound and a sampled drum kit. They're there whenever the stock sampler screen shows; while op1r's sample editor is open, they step aside.

## Who made it

Rebuilt by hundekraft from how Maiko Pruett's #249 and #250 work; none of Maiko's code is used.

## Get it

Sampler tools is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
