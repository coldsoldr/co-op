# Snowglobe

*Shimmer reverb with a frozen heart.*

A shimmer reverb whose tail climbs an octave at a time. At the top of orange the tail freezes into a pad that holds until you turn back.

## Get it

Snowglobe is part of hundekraft 3.3.1, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.

On op1r 72 it is the plugin file `snowglobe.op1p`: tick it in [op1r's web patcher](https://pcppcp.github.io/op1r/web/) (Connect OP-1 installs it over USB), or download it here with op1r chosen in Settings.
