# Taffy

*Elastic, CZ-style phase distortion.*

Phase distortion in the style of Casio's CZ synths. A plain cosine is bent out of shape: the more you bend it, the brighter it gets. There is no filter. Brightness comes from the bend, so the sound stays clean and a little glassy.

## Get it

Taffy is part of hundekraft 3.3.1, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.

On op1r 73 it is the plugin file `taffy.op1p`: tick it in [op1r's web patcher](https://pcppcp.github.io/op1r/web/) (Connect OP-1 installs it over USB), or download it here with op1r chosen in Settings.
