# MIDI CC control

A computer, a controller or a MIDI track can turn the current synth's knobs with CCs on the OP-1's MIDI channel. It works like turning the knob and is saved in the sound.

## Who made it

From op1r, ported to kennel by Hundekraft.

## Get it

MIDI CC control is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
