# Bitcrush

bitcrush, by LizardMan, lowers the sample rate and the bit depth, from a gentle grit down to a buzzing one-bit square. The curve in the middle of the screen shows what it does to a sine as you turn.

## Get it

Bitcrush is part of hundekraft 3.3.1, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
