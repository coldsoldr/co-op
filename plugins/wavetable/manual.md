# Wavetable

*Morphing waves. Analog ladder filter.*

Two slightly detuned oscillators read eight single-cycle waves and morph between them. The sound then goes through a four-pole ladder low-pass filter that can scream when you push it. Think classic analog pads and acid lines, with some vocal and digital colours on top.

## Get it

Wavetable is part of hundekraft 3.3.1, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.

On op1r 73 it is the plugin file `wavetable.op1p`: tick it in [op1r's web patcher](https://pcppcp.github.io/op1r/web/) (Connect OP-1 installs it over USB), or download it here with op1r chosen in Settings.
