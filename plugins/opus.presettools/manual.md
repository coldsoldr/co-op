# preset tools

Overwrite save, rename and delete for the presets you saved, a flash drive's presets too. Part of Opus since beta 5, a row in the menu's system list: delete an old presettools.opmod from the mods folder. It replaced Opus 1's rename and overwrite save in beta 4.

## Get it

preset tools 1.3.0 is a plugin for Opus 2.0 beta 5, LizardMan's mod for the original OP-1 (firmware 246): one file in the starter pack, or on its own, in [Opus's releases](https://github.com/LizardMan245/opus/releases). Copy the `.opmod` into the mods folder on the OP-1's disk. co-op lists it for reference and hosts no copy. Opus's plugins are © LizardMan, free to use and share.
