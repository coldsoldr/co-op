# C64 arpeggiator

*An editable pitch table with per-step dwell time.*

Choose C64arp in the sequencer browser: hold Shift and press SEQ, turn blue to c64arp, then press SEQ to load it. With seq on, hold a note to set the root of its repeating table of relative pitches. Turn orange right to hold the notes after you let go, like the stock arpeggio, and left to release them. A step can last several base steps, so a short table can produce uneven rhythms.

## Get it

C64 arpeggiator is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
