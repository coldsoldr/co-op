# Tape

*Vintage tape echo.*

A tape echo with a moving tape loop on screen. The animation is locked to the audio: a mark takes exactly the delay time to travel from the record head to the play head.

## Who made it

From op1r, ported to kennel by Hundekraft.

## Get it

Tape is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
