# Chord mode

Chord mode turns every key into a chord. It knows about scales and progressions, so you can play a whole song with one finger. It works with every synth, including the stock ones, and with every sequencer. It's off until you switch it on.

## Who made it

Voicings and strums from op1r.

## Get it

Chord mode is part of hundekraft 3.3.1, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.

On op1r 72 it is the plugin file `chord.op1p`: tick it in [op1r's web patcher](https://pcppcp.github.io/op1r/web/) (Connect OP-1 installs it over USB), or download it here with op1r chosen in Settings.
