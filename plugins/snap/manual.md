# SNAP

*Pitch correction, from polite to obvious.*

SNAP pulls your singing onto the notes. It takes your voice from the OP-1's input, like Amp, and moves each note you sing to the nearest note of the key. Set gently, it nudges a shaky note into tune so nobody notices. Set hard, every note snaps to the key, the sound everyone knows from the radio. Hold keys and each one adds a copy of your voice at that key's pitch, with the key's envelope, so one chord gives you a small choir of yourself. A tuner needle shows how far off you sang.

## Get it

SNAP is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
