# fx overdrive

A second effect behind every sound's effect and the master's: any effect from the list, a downloaded one too. Part of Opus since beta 5: its row in the menu's system list switches the second effect off entirely. Delete an old overdrive.opmod from the mods folder.

## Get it

fx overdrive 2.3.0 is a plugin for Opus 2.0 beta 5, LizardMan's mod for the original OP-1 (firmware 246): one file in the starter pack, or on its own, in [Opus's releases](https://github.com/LizardMan245/opus/releases). Copy the `.opmod` into the mods folder on the OP-1's disk. co-op lists it for reference and hosts no copy. Opus's plugins are © LizardMan, free to use and share.
