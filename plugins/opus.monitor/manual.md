# monitor

Hold FN on any page to see what the OP-1 and every plugin cost: the CPU, the audio's load, its worst block and the blocks that came late, frames a second, memory, the OS's threads and the last crash. Fullscreen dims the page as the OP-1's help does; popup puts the main figures in a small box in a corner. It takes no key or turn, so everything plays on underneath, and a plugin shows red only while it goes over its CPU budget or is switched off. For the curious and for plugin authors. It shares FN held with stock help: switch stock help off in the mods list to use it.

## Get it

monitor 0.1.4 is a plugin for Opus 2.0 beta 4.1, LizardMan's mod for the original OP-1 (firmware 246): a download of its own beside the starter pack, in [Opus's releases](https://github.com/LizardMan245/opus/releases). Copy the `.opmod` into the mods folder on the OP-1's disk. co-op lists it for reference and hosts no copy. Opus's plugins are © LizardMan, free to use and share.
