# Tape markers

On the tape screen:

Up to 32 markers, saved with the tape. Plain orange still sets the record level.

## Who made it

From op1r, ported to kennel by Hundekraft.

## Get it

Tape markers is part of hundekraft 3.2.6, a custom firmware for the original OP-1. Tick it in the [hundekraft workshop](https://hundekraft.github.io/op1-workshop/) and install it from there. co-op lists it for reference and hosts no copy.
