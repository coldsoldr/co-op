# Test Tones

Three plain sine-tone patches for checking that installing a pack onto an OP-1 works. They
are not instruments and are not meant to sound good.

| File | Kind | Audio |
| --- | --- | --- |
| `synth/tone-cluster.aif` | synth (cluster) | 0.5 s, 220 Hz sine, AIFF |
| `synth/tone-sampler.aif` | synth (sampler) | 0.5 s, 261.63 Hz sine, little-endian AIFC |
| `drum/tone-drum.aif` | drum | 24 slices of 0.1 s, sines a semitone apart from 110 Hz, AIFF |

## Provenance

All three files are generated by `web/scripts/make-test-tones.ts` in this repository. The
audio is computed sine waves and the drum slice points are evenly spaced; no recording or
third-party sample is involved. The synth, effect and LFO parameter values in the patch
metadata are the defaults used by the [teoperator](https://github.com/schollz/teoperator)
project (MIT licence), credited here with thanks.

The drum slice points use a scale of 4058 position units per sample frame.
That scale is inferred, not verified on hardware: in a real OP-1 drum file the
last slice end divided by the frame count is 4057.97, and each slice starts
exactly 4058 units (one frame) after the previous one ends. If the slices of
`tone-drum` sit in the wrong place on your OP-1, please open an issue.
