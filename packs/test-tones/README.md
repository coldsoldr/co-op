# Test Tones

Three plain sine-tone patches for checking that installing a pack onto an OP-1 works. They
are not instruments and are not meant to sound good.

| File | Kind | Audio |
| --- | --- | --- |
| `synth/cluster.aif` | synth (cluster) | 0.25 s, 220 Hz sine, AIFF |
| `synth/sampler.aif` | synth (sampler) | 0.25 s, 261.63 Hz sine, AIFC little-endian (sowt) |
| `drum/boombap.aif` | drum | 0.5 s, 110 Hz sine, AIFF |

The files are byte-for-byte copies of the synthetic test fixtures in `web/test/fixtures`
(`synth-cluster.aif`, `synth-sampler-sowt.aif`, `drum-boombap.aif`), generated by
`web/test/fixtures/build-fixtures.ts`. The audio is computed sine waves written by this
repository; no recording or third-party sample is involved, so the pack is released under
CC0-1.0 (public domain dedication).
