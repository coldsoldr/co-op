# melod1c

Melodic synth patches collated from [op1.fun](https://op1.fun). Each one keeps the credit
and the licence its author gave it there.

| File | Kind | Author | Licence | Source |
| --- | --- | --- | --- | --- |
| `synth/alesis-marimba-14990.aif` | synth (sampler) | mrbendel | CC BY-SA 4.0 | [Alesis Marimba](https://op1.fun/users/mrbendel/patches/alesis-s4-plus-s) |
| `synth/koto_glitch-4031.aif` | synth (sampler) | captainearwax | CC BY-SA 4.0 | [Koto_glitch](https://op1.fun/users/captainearwax/patches/koto_glitch) |
| `synth/planks-3845.aif` | synth (cluster) | alanholding | CC BY 4.0 | [planks](https://op1.fun/users/gentlemanhog/patches/planks) |
| `synth/sparkle-17761.aif` | synth (sampler) | ByronJZA | CC BY-SA 4.0 | [sparkle](https://op1.fun/users/byronjza/patches/sparkle) |

The number in each file name is the patch's id on op1.fun.

`koto_glitch` is, in its author's words, a Zoom recording of a koto and sitar hybrid
instrument made in Lyon, with glitch effects from Sinevibes Sequential and Logic's tape delay.

The pack is listed under CC-BY-SA-4.0. `planks` stays under its own CC BY 4.0 licence.
