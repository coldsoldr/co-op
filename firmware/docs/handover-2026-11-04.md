Surveyed (stock disassembly): punch, phone, nitro, spring (stereo), grid (stereo) and delay (stereo) are compiled
hardware loops with no per-sample CALLs. They gain from hand scheduling (parallel loads, state in registers, dual MAC
for the dual-mono ones) rather than from removing calls: expect 20-40 % each. Not yet measured: the other synth
engines (FM, Cluster, Digital, Pulse, String, Phase, Sampler, the drum engines).

## How to work (proven today)

- **Build**: `wsl -e bash -lc 'cd /mnt/i/GitHub/coldsoldr/coop-fw && make -C core/sdram combined'`; touch the .cc
  after a header change (the Makefile has no header dependencies). Emulator image:
  `tools/build_image.sh ~/op1emu-work/X.ldr --tape-stereo --set-word g_coop_spread=32767 --set-word
  g_coop_force_stereo_out=1 [--set-word g_coop_fast_X=0]`. Device package: `tools/build_device_package.sh
  build/pkg/NAME.op1 --tape-stereo --set-word g_coop_spread=32767` (it runs the bootloader check; "mismatches 1" =
  only OP1_vdk.ldr differs, as intended); copy to `/mnt/c/Users/byron/Downloads/`.
- **A/B**: `tests/sim/ab_switch.sh g_coop_fast_X SCENARIO [COST_INDEX] [FROM]` (run from the repo root in WSL).
  Scenarios: `det_dsynth6` (six-voice DSynth), `det_dsynth6_cwo` (with cwo), `det_fx_stock_{cwo,phone,grid,spring,
  nitro,delay}` (an effect at the synth), `det_chord`, `det_drum`, `det_tape_rec`, `det_ui_slot2`. Write new
  `det_fx_stock_punch.txt` etc. from `det_fx_stock_phone.txt` (FX list rows: cwo, delay, grid, nitro, phone, punch,
  spring; 8 quarter-steps per row; a row-0 selection needs one row down and back up). Run emulator jobs one at a
  time; never build while one runs.
- **Reading the result**: a faster callback moves key events by whole blocks, so check per-second levels
  (`tools/wav_levels.py`) and the offset residual; differences at frame 0 of 1-2 LSB are the emulator's two-state
  run-to-run variation. Always A/B in two scenarios.
- **Simulator check** for code with a C reference: add it to `tests/sim/kern_check.cc`; `tests/sim/run_kern_check.sh`.
- **Stock disassembly**: `C:\Users\byron\AppData\Local\Temp\claude\I--GitHub-coldsoldr-coop-fw\396e0c7d-72e9-4be4-ab0e-160090d794e3\scratchpad\dis\stock.dis`
