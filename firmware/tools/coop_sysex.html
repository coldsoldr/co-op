coop SysEx file reader

Reads a file from the running OP-1 over USB-MIDI (coop-fw milestone U1, core/sdram/coop_sysex.cc). Chrome or Edge with Web MIDI; plug the OP-1 in, pick its MIDI port, say hello, then read.

Second effect slot (S2)

A second effect after the instrument effect and after the master effect. It runs whether or not the OP-1's own effect is on, and the OP-1 keeps the choice across power cycles. Read the slots first: that also lists the installed plugins.

Not connected.
