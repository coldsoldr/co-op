coop SysEx tool

Reads a file from the running OP-1 over USB-MIDI (coop-fw milestone U1, core/sdram/coop_sysex.cc). Chrome or Edge with Web MIDI; plug the OP-1 in, pick its MIDI port, say hello, then read.

Second effect slot (S2)

A second effect after the instrument effect and after the master effect. It runs whether or not the OP-1's own effect is on, and the OP-1 keeps the choice across power cycles. Read the slots first: that also lists the installed plugins.

Run a test (p5b)

Plays a test script on the OP-1 (key presses and knob turns at exact times, docs/test-runner.md) while this page records the OP-1's audio from your interface; at the end it fetches the run results and the stats file. Pick a script from tests/sim/ (for example run_p5a.txt). The test plays the sound slots and effects it names and leaves them as it set them, so save anything you care about first. Hands off the OP-1 while it runs; Stop releases every key it holds.
