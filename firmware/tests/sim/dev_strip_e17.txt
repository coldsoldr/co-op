# Device loop (tools/devloop.py --allow-tape): the e17 channel strip on the real OP-1 (docs/device-tests.md "e17").
# Before: a tape with content on track 1 (and ideally 2-4), a tape loop on around it (about 90 s of play), the tape
# at the loop start, master FX 1 set to an effect with an audible tail (the stock delay is enough); nothing recorded.
# What it does: Settings > VOICES "channel strip" on; mixer T1; blue push opens tape 1's strip; play; then section by
# section on tape 1: neutral, EQ (band 1 +12 dB), comp, sat, FX 1 send 100 %, FX only (dry 0); then strips on tapes
# 2-4 with every section on (the four-strip cost); stop, wait for the save; strip mode off in Settings; play again
# (should sound like "neutral"). Never presses rec / lift / drop / split / mic, never shift + T (mute).
# Sections: the run file gives each section's engine costs, summary.json the recording's level per section.
# Leaves: strip mode off; tape 1-4 strips keep these settings in coop_strip.bin (inactive while the mode is off).
